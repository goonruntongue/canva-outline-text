App walkthrough

Fuchidori by FlashMelody K.Murakami · 日本語

About 80 seconds, no sound. Captions are in English and Japanese. Open the video file

What the video shows

  1. Type the text. Line breaks are kept.
  2. Change the font from Dela Gothic One to Noto Sans JP.
  3. Switch the fill from Solid to Gradient.
  4. Click the gradient bar to add a color stop, then drag it.
  5. Pick the stop color with Canva's color picker.
  6. Set the gradient angle.
  7. Choose the corner style (Round, Miter or Bevel).
  8. Set the width of each outline layer.
  9. Select Add to design. The result is added as an image.
  10. Select the image again. The settings load into the panel. Edit them, then select Update selected element.

操作動画

約80秒・音声なし・英語と日本語の字幕付きです。

動画の内容

  1. 文字を入力します（改行もそのまま使えます）。
  2. フォントを Dela Gothic One から Noto Sans JP に変えます。
  3. 塗りを単色からグラデーションに切り替えます。
  4. グラデーションのバーを押してカラーストップを追加し、ドラッグで動かします。
  5. Canva のカラーピッカーでストップの色を選びます。
  6. グラデーションの角度を調整します。
  7. 角の結合（ラウンド／マイター／ベベル）を選びます。
  8. アウトラインの層ごとに太さを調整します。
  9. 「デザインに追加」を押すと、画像として配置されます。
  10. 画像を選び直すと設定がパネルに戻ります。直して「選択中の要素を更新」を押します。
