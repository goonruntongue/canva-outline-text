Frequently asked questions

Where do I find the app?

In a Canva design, select Apps in the side panel and search for Fuchidori. After you use it once, it also appears in the side panel.

Can I edit the outlined text after adding it?

Yes. With the app open, select the outlined text in your design. Your settings load into the panel. Make your changes, then select Update selected element.

Why can't I edit the text with Canva's text tool?

Fuchidori adds the outlined text as an image so that every outline layer and corner style looks exactly as previewed. To change it, use the app as described above.

A message says the font couldn't be loaded.

The built-in fonts are downloaded from Google Fonts. If your connection is unavailable, a substitute font is shown. Check your internet connection and reopen the app.

My uploaded font isn't available when I edit later.

Uploaded font files stay in your browser and are not saved. When you edit text that used an uploaded font, upload the same font file again.

Can I use Canva's own fonts?

No. Canva doesn't let apps use its font library, so Fuchidori provides its own fonts and supports font file uploads.

よくある質問

アプリはどこから開けますか？

Canvaのデザイン画面で、左のメニューの「アプリ」から「Fuchidori」を検索してください。一度使うと、左のメニューにも表示されます。

追加した文字をあとから直せますか？

はい。アプリを開いた状態でデザイン上の縁取り文字を選ぶと、設定がパネルに読み込まれます。変更したら「選択中の要素を更新」を押してください。

Canvaの文字ツールで直せないのはなぜですか？

縁取りの重なりや角の形をプレビューどおりに再現するため、画像として追加しています。直すときは上の方法でアプリから編集してください。

「フォントを読み込めなかった」と表示されます。

内蔵フォントはGoogle Fontsから読み込んでいます。通信できないときは代わりのフォントで表示します。通信環境を確認し、アプリを開き直してください。

読み込んだフォントが、あとで編集するときに使えません。

読み込んだフォントファイルはブラウザの中だけで使い、保存しません。そのフォントを使った文字を編集するときは、同じフォントファイルをもう一度読み込んでください。

Canvaのフォントは使えますか？

Canvaはアプリがフォントライブラリを使うことを認めていないため、使えません。代わりに独自のフォントとフォントファイルの読み込みに対応しています。
